データ

入力内容はこのブラウザに自動保存されます。JSONで書き出して保管・移行できます。

GitHub 同期

記録・編集・削除・設定変更のたびに、数秒後に自動で GitHub へ commit します。起動時は未同期の変更があれば先に送信し、なければ GitHub の内容で置き換えます。PAT は対象リポジトリ1つ・Contents: Read and write で発行してください。

JSON出力

出力には約定ログ・設定・現在値に加え、再計算結果 (derived: 決済済み・保有) も入ります。derived は読み取り専用で、取り込み時は無視されます。

取り込み

方法

本アプリのJSON、または従来の stock_data.csv (datetime / F / Code / name … 形式) を自動判別して読み込みます。

設定

従来の「実質額 = 利益 × 0.8」は、利益時80%・損失時100%に相当します。損失側にも0.8を掛けると損失が小さく見えるため、既定では分けています。

初期化

削除前に必ずJSONを書き出してください。元には戻せません。
